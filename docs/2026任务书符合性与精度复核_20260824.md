# 2026 北航导航系实习任务书符合性与精度复核

复核日期：2026-08-24  
依据文件：`2026北航导航系实习任务书(1).docx`  
复核对象：STM32F103RC + AD7124-8 + PressureOS Qt 上位机 + 7 英寸 1024×600 触控屏

## 1. 结论先行

1. 当前系统已经满足或具备明确证据的项目包括：指定 MCU/ADC、压力与温度实时显示、原始值/处理值显示、五种滤波方案、单位切换、SQLite 存储、任务分析、1024×600 触控交互，以及 **12.936 Hz** 的真实压力采样率。
2. 当前系统的压力显示分辨力按 `0.1 kPa` 设计；温度显示到 `0.1 ℃`。这能证明显示分辨力，最终仍应结合静态噪声和重复性确认“有效分辨力”。
3. **目前不能宣称达到 0.02 级或 0.05 级压力准确度。** 当前参数对历史检定表回算的最大误差约为 `1.665 kPa`，约等于 `0.238%FS`，明显大于 0.05 级允许的 `0.35 kPa`。
4. 历史数据重新进行二次拟合后，拟合点最大残差约为 `0.108 kPa`，数值上存在冲击 0.02 级的潜力；但该结果来自拟合数据本身，且原表缺少表头、标准器、设备编号、完整量程和独立复检信息，不能作为准确度验收结论。
5. “至少两种非线性校正算法”已有独立 Python 原型（整体多项式、动态分段多项式），但尚未完整接入 PressureOS 的触控标定流程、参数版本管理和独立复检闭环，因此当前判定为“部分完成”。

## 2. 准确度判据与当前结果

任务书压力范围为 `−100～600 kPa`，满量程跨度为：

```text
FS = 600 − (−100) = 700 kPa
```

若等级按满量程百分比计算：

| 目标 | 最大允许误差 |
|---|---:|
| 0.02 级 | ±0.02%FS = **±0.14 kPa** |
| 0.05 级 | ±0.05%FS = **±0.35 kPa** |

当前上下位机共同使用的压力换算式为：

```text
P = 3.3631e-13 × Raw² + 2.0807e-4 × Raw − 102.2342
```

用该公式复核 `docs/检定.xlsx`（按既有复核假设处理疑似录入错误和旧增益原码换算）得到：

| 指标 | 结果 |
|---|---:|
| 平均偏差 | 约 −1.080 kPa |
| 均方根误差 | 约 1.152 kPa |
| 最大绝对误差 | **约 1.665 kPa** |
| 折算满量程误差 | **约 0.238%FS** |

因此，就现有证据而言，当前公式既不能证明 0.02 级，也不满足 0.05 级。程序继续保持“标定待确认”，不得设置 `PRESSUREOS_VALUE_TRUSTED=1`。

## 4. 本轮界面与安全表述整改

1. 正常测量时删除“量程保护待验收”提示，只有进入 80%/90%/98% 风险区或数据异常时才出现必要警示。
2. 删除独立量程保护进度条，把空间归还实时趋势图。
3. 安全监测中删除“硬件切断”能力，统一改为“风险报警 + 人工停止加压 + 人工缓慢泄压”，避免虚假安全承诺。
4. 测量状态的三个图标改为持久组件，只更新文字和值，不再随采样帧销毁重建，从根因消除闪烁。
5. 主波形使用最近 15 秒窗口；点击波形或“全屏波形”可进入 1024×600 专注模式，并可切换 15 秒、30 秒和全部数据。
6. 纵轴根据当前窗口内原始值和滤波值的全部真实极值自动扩展，不使用分位数裁剪，保证突变峰值不会被隐藏。
7. 纵轴和背景按量程利用率着色：80% 黄色提醒、90% 橙色警告、98% 红色高风险；不再单独占用量程条空间。

## 5. 准确度闭环的最短实施路径

1. 核对标准器型号、编号、量程、准确度/不确定度、有效期和连接方式。标准器能力应明显优于目标允许误差。
2. 固定当前传感器、PCB、PGA、ADC 滤波、固件和采样率，建立唯一设备/参数版本，禁止标定过程中更换配置。
3. 覆盖 `−100～600 kPa` 做升程和降程；建议至少包含 `−100、−80、−50、0、50、100、200、300、400、500、600 kPa`，每点稳定后重复采集不少于 3 次，并最终回零。
4. 同时保存标准值、原始码、滤波码、STM32 示值、PressureOS 示值、温度、时间、升/降程方向和稳定性。
5. 分别计算整体二次/三次多项式和分段模型，比较最大绝对误差、回程误差、重复性和残差，而不是只比较 R²。
6. 用未参与拟合的独立复检数据验收。只有所有复检点均满足目标误差，才能生成并启用正式参数版本。
7. 参数需要同时固化到 STM32 和 PressureOS，启动时回读版本和校验值；上下位机示值逐点一致后，再启用量值可信标志。
8. 正式采数前校准树莓派系统时间或配置可靠 NTP/RTC。现场检查时树莓派仍显示 2026-08-21，比实际日期慢约三天；若不修正，会破坏任务排序和检定记录的时间可追溯性。
