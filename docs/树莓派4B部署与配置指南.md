# PressureOS 树莓派 4B 部署与配置指南

适用硬件：Raspberry Pi 4 Model B 4 GB、32 GB TF 卡，以及装箱清单第 4 项的 7 英寸 HDMI 触摸屏。现有资料未写明这块 7 英寸主屏的完整型号和原生分辨率，部署时应以 EDID 实际识别结果为准。建议使用 Raspberry Pi OS 64-bit Bookworm Desktop。

## 1. 首次安装

用 Raspberry Pi Imager 写入系统时预先设置主机名、用户、Wi-Fi、时区 `Asia/Shanghai` 和 SSH。首次启动后执行：

```bash
sudo apt update
sudo apt full-upgrade -y
sudo reboot
```

建议使用稳定的 5 V/3 A USB-C 电源。显示器的 HDMI 与触摸 USB 必须都连接；触摸 USB 不只是供电线。

## 2. 安装构建与运行依赖

```bash
sudo apt install -y \
  build-essential cmake ninja-build pkg-config git sqlite3 \
  qt6-base-dev qt6-declarative-dev qt6-tools-dev qt6-tools-dev-tools \
  qml6-module-qtquick qml6-module-qtquick-window \
  qml6-module-qtquick-controls qml6-module-qtquick-layouts \
  qml6-module-qtquick-dialogs qml6-module-qtqml-workerscript \
  libqt6sql6-sqlite fonts-noto-cjk \
  libinput-tools evtest
```

确认版本：

```bash
cmake --version
qmake6 -query QT_VERSION
```

工程以 Qt 6.4 为兼容基线。若发行版缺少某个 `qml6-module-*` 包，用 `apt search qml6-module-qtquick` 查看本机名称，不要混装 Qt 5 QML 模块。

## 3. 复制源码

从开发电脑复制：

```powershell
scp -r .\PressureOS_Qt_Demo pi@pressureos.local:/home/pi/PressureOS_Qt_Demo
```

也可使用 Git 或 U 盘。源码目录建议只使用英文路径，避免第三方 QML 工具的编码问题。

## 4. 编译

```bash
cd ~/PressureOS_Qt_Demo
chmod +x scripts/build_raspberry_pi.sh
./scripts/build_raspberry_pi.sh
```

等价的手动命令：

```bash
cmake -S . -B build-rpi -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=/opt/pressureos
cmake --build build-rpi --parallel 4
```

先运行后端回归测试，确认 SQLite、任务、导出和模拟安全状态机正常：

```bash
ctest --test-dir build-rpi --output-on-failure
```

先用窗口模式验证：

```bash
./build-rpi/pressureos --windowed
```

再测试全屏：

```bash
./build-rpi/pressureos --fullscreen
```

## 5. 安装到系统目录

```bash
sudo cmake --install build-rpi
sudo mkdir -p /opt/pressureos/share
sudo chown -R root:root /opt/pressureos
```

CMake 默认把可执行文件安装为 `/opt/pressureos/bin/pressureos`。QML 已编译进资源，不需要单独复制页面目录。

## 6. 7 英寸显示和触摸

### 6.1 先区分资料包中的两块屏

- `实践套件装箱清单 V2.0.pdf` 将 `ConST Sensor Study Kit` 和“7 英寸高清触摸显示屏”分别列为第 3、4 项；PressureOS 主界面运行在第 4 项上。
- `07 屏幕规格书LS027B7DH01.pdf` 是一份完整屏幕规格书，但其第 7 页明确写明：2.7 英寸、400×240、单色、串行通信的 Memory LCD。它对应套件板载小屏，不是树莓派的 7 英寸 HDMI 触摸主屏。
- 因此不能用 `LS027B7DH01` 的 400×240 参数配置 PressureOS，也不能在缺少依据时把 7 英寸主屏固定宣称为 1280×800。

### 6.2 读取主屏 EDID

先查看系统识别结果：

```bash
wlr-randr
libinput list-devices
```

优先采用 `wlr-randr` 中标有 `current`/`preferred` 的模式，不写死分辨率。PressureOS 已以 1024×600 作为保守布局基准，并保持对 1280×800 等更大画布的响应式适配。

只有 EDID 识别失败或输出模式明显错误时才强制设置。先确认屏幕实测原生模式和 HDMI 接口名，再在 `/boot/firmware/cmdline.txt` 的同一行末尾追加相应参数。例如，只有当实测原生模式确为 1024×600 时才使用：

```text
video=HDMI-A-1:1024x600@60D
```

若 EDID 确认的是 1280×800，则把参数改成 `1280x800@60D`。接口名也可能是 `HDMI-A-2`，一切以 `wlr-randr` 输出为准。改完后重启；不要在未确认接口名和原生模式时同时写多个强制模式。

触摸测试：

```bash
sudo evtest
```

选择触摸设备后，屏幕四角应有连续坐标。常见 USB HID 触摸无需安装驱动。若显示旋转，先用桌面“Screen Configuration”旋转输出，再确认触摸映射；不要只旋转 QML 页面。

建议保留 EDID 推荐模式和 100% 桌面缩放。应用按约 48 逻辑像素触控目标设计，不建议开启 150% 桌面缩放。

## 7. 串口与 USB 权限

CH341 和 CP210x 在 Raspberry Pi OS 中通常由内核直接支持，不需要安装资料包里的 Windows 驱动。

插入下位机后检查：

```bash
lsusb
dmesg --follow
ls -l /dev/ttyUSB* /dev/ttyACM* 2>/dev/null
udevadm info --query=property --name=/dev/ttyUSB0 | sort
```

把运行用户加入串口组：

```bash
sudo usermod -aG dialout "$USER"
sudo reboot
```

重启后验证：

```bash
groups
test -r /dev/ttyUSB0 -a -w /dev/ttyUSB0 && echo "serial permission ok"
```

公司确认 VID/PID 后再编写精确 udev 规则，例如：

```text
SUBSYSTEM=="tty", ATTRS{idVendor}=="xxxx", ATTRS{idProduct}=="yyyy", \
  SYMLINK+="pressureos-px01", GROUP="dialout", MODE="0660"
```

不要现在猜测 `xxxx/yyyy`，也不要对所有 tty 设备设置 `0666`。

## 8. Wi-Fi 与蓝牙检查

Bookworm 默认使用 NetworkManager：

```bash
nmcli device status
nmcli radio wifi on
nmcli device wifi list
nmcli device wifi connect "PressureLab-5G" password "你的密码"
```

蓝牙：

```bash
rfkill list
sudo rfkill unblock bluetooth
bluetoothctl show
```

Demo 页面里的网络和配对是模拟状态。正式版本中建议蓝牙只负责发现/首次配网，模板与曲线通过局域网 HTTPS/WSS 传输。

## 9. 开机自启动（推荐桌面自启动）

Bookworm 桌面会话已建立 Wayland 环境，因此 `.desktop` 是最稳定的 GUI 自启动方式：

```bash
mkdir -p ~/.config/autostart
cp deploy/pressureos.desktop ~/.config/autostart/
chmod 644 ~/.config/autostart/pressureos.desktop
```

注销并重新登录测试。需要延迟等待 USB 设备时，把 `Exec` 改为：

```text
Exec=sh -c 'sleep 2; /opt/pressureos/bin/pressureos --fullscreen'
```

不推荐直接使用系统级 root service 启动 GUI。若必须用 systemd user service：

```bash
mkdir -p ~/.config/systemd/user
cp deploy/pressureos.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now pressureos.service
journalctl --user -u pressureos.service -f
```

如果服务找不到 Wayland socket，在桌面终端执行：

```bash
systemctl --user import-environment WAYLAND_DISPLAY DISPLAY XDG_RUNTIME_DIR
systemctl --user restart pressureos.service
```

## 10. 数据库与备份

定位数据库：

```bash
find ~/.local/share -name pressureos_demo.sqlite -print
```

应用运行时采用 WAL。在线备份不要只复制主文件，使用 SQLite 备份命令：

```bash
sqlite3 /path/to/pressureos_demo.sqlite ".backup '/home/pi/pressureos-backup.sqlite'"
```

查看完整性：

```bash
sqlite3 /path/to/pressureos_demo.sqlite "PRAGMA integrity_check;"
```

正式部署建议每天备份任务元数据和标定参数；大体量原始样本按任务归档，禁止自动覆盖有效标定记录。

如需进行不会污染正式任务的验收，可在启动前设置独立目录：

```bash
export PRESSUREOS_DATA_ROOT="$HOME/pressureos-qa/data"
export PRESSUREOS_EXPORT_ROOT="$HOME/pressureos-qa/export"
```

生产自启动不要设置这两个测试变量，除非该目录已经纳入正式备份和权限方案。

## 11. 性能与稳定性建议

- 使用 Release 构建，不在树莓派上长期运行 Debug/QML调试器。
- 实时曲线读取内存环形缓冲区，历史数据才查 SQLite。
- 50 Hz 数据使用批量事务；不要在 QML 每个采样点执行 SQL。
- 不需要人为调大 GPU memory，先保持系统默认 KMS 设置。
- 关闭屏保和自动休眠，避免答辩演示时熄屏。
- 每次异常退出后检查 `journalctl --user -u pressureos` 和数据库完整性。

可在桌面设置中关闭屏幕空白，或按实际桌面环境配置电源管理。不要关闭系统日志和文件系统同步来换取表面速度。

## 12. 从模拟器切换到真实硬件

1. 向公司确认串口芯片、VID/PID、波特率、帧结构、CRC、命令字和样例帧。
2. 安装 Qt SerialPort 开发包：`sudo apt install qt6-serialport-dev`。
3. 实现 `SerialTransport`、`ProtocolCodec` 和 `SerialDeviceGateway`。
4. 在 `main.cpp` 依据配置选择模拟或真实网关。
5. 保持压力单位统一为核心层 kPa，页面显示时再换算。
6. 用同一压力点同时记录公司上位机、STM32原始帧和 PressureOS 结果进行对照。
7. 完成断线重连、CRC错误、序号跳变、超量程和数据库断电恢复测试后，才关闭 Demo 标识。

软件联锁通过不等于硬件安全验收通过。真实设备必须另外完成独立压力开关/比较器、MCU 看门狗、继电器或阀反馈、断电安全态和人工复位测试，接口清单见 `docs/硬件安全联锁接口说明.md`。

## 13. 部署验收清单

- [ ] 冷启动后 10 秒内进入首页。
- [ ] EDID 推荐分辨率下无裁切，Dock 不遮挡主操作；至少复核 1024×600 基准布局。
- [ ] 单指点击、输入框和滑动列表工作正常。
- [ ] 运行 30 分钟无明显内存增长或界面卡顿。
- [ ] 记录 50 Hz 数据后样本数与时长匹配。
- [ ] 拔插 USB 后状态提示明确，当前任务不丢失。
- [ ] 杀死界面进程或断开树莓派后，独立硬件保护仍能切断压力源。
- [ ] 联锁动作后必须泄压、排除故障并由本机人工确认才能复位。
- [ ] Wi-Fi 断开时核心测量与任务仍可用。
- [ ] 重启后任务点与用户模板仍存在。
- [ ] CSV 可在另一台电脑正确显示中文与小数。
- [ ] 自启动、退出恢复和数据库备份均验证。

## 14. 常见问题

`module "QtQuick.Controls" is not installed`：缺少对应 `qml6-module-*` 运行包。

`QSQLITE driver not loaded`：安装 `libqt6sql6-sqlite`，并检查 `QT_DEBUG_PLUGINS=1` 输出。

串口 Permission denied：确认用户属于 `dialout`，加入组后必须重新登录或重启。

窗口黑屏：先取消强制显示参数，用 `QT_LOGGING_RULES="qt.rhi.*=true"` 启动检查图形后端；不要立即切换到老式 framebuffer 插件。

中文为方框：安装 `fonts-noto-cjk` 后执行 `fc-cache -f -v`。
