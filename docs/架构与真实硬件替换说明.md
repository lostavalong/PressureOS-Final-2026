# 架构与真实硬件替换说明

## 1. 运行时职责

```text
ConST-EDU压力桥/PT100
        ↓
AD7124-8 + STM32F103
  采样、CRC、基础滤波、压力反算、温补
        ↓ USB串口
Raspberry Pi / PressureOS C++核心
  设备网关 → 测量状态 → 任务引擎 → 计算 → SQLite/报告
        ↓ QObject属性、信号和列表
Qt Quick / QML
  全屏应用、触控交互、图表、助手
        ↓ P2阶段 REST/WebSocket
微信小程序
  辅助输入、查看、模板上传和分享
```

正式结果的唯一权威端是树莓派。小程序可以显示和提交数据，但任务版本、算法版本、计算结果和审计记录均以树莓派为准。

## 2. 当前 Demo 的数据闭环

1. `DeviceSimulator` 每 20 ms 生成压力、温度和时间戳。
2. 模拟器维护原始、滤波和温补值，并用最近 50 点极差判断稳定性。
3. QML 通过只读属性显示实时值；曲线每 3 个样本批量刷新一次。
4. 开始记录时建立 `measurement_sessions`，样本进入内存缓冲区。
5. `DatabaseService` 每 500 ms 或每 100 点使用一次事务批量写入。
6. 任务采点时保存外部变量、稳定压力、数据来源和时间戳；采点、删点、切换和阶段变化均立即落盘。
7. `TaskManager` 自动重算最小二乘拟合、R/R²、逐点残差、异常点预筛和演示不确定度。
8. 同一任务保存当前阶段和状态，可在多个任务间切换后原位恢复。
9. 导出时一次生成 CSV 原始表、JSON 分析证据包和 SVG 矢量图。
10. 页面只消费核心层结果，不自行计算正式统计量。

## 3. 真实串口替换点

接口冻结后新增下列实现，并保持对 QML 暴露的属性名称不变：

```text
DeviceGateway
├─ SimulatorGateway             当前演示实现
└─ SerialDeviceGateway          正式实现
   ├─ SerialTransport           端口发现、收发、缓存、重连
   ├─ ProtocolCodec             帧头、长度、序号、CRC与版本兼容
   ├─ CommandDispatcher         ACK、超时和重试
   └─ SampleMapper              协议字段转统一MeasurementSample
```

统一样本至少包含：

| 字段 | 类型 | 单位/说明 |
|---|---:|---|
| sequence | uint32 | 下位机递增序号 |
| deviceTimestamp | uint64 | 下位机时间，需定义时基 |
| adcCode | int32 | AD7124 原始码 |
| rawPressure | double | kPa |
| filteredPressure | double | kPa |
| compensatedPressure | double | kPa |
| temperature | double | ℃ |
| algorithmId | string | 温补/滤波算法版本 |
| statusFlags | uint32 | 超量程、开路、CRC等状态 |

协议必须先明确：波特率、字节序、帧头、转义规则、长度、消息类型、序号、时间戳、CRC算法、ACK/NACK、超时和错误码。CH341/CP210x 只是 USB 转串口芯片，不能推导出这些应用层字段。

## 4. 数据库表

当前建库包含：

- `measurement_sessions`：自由测量会话和设置快照。
- `samples`：原始、滤波、温补压力、温度和有效状态。
- `task_runs`：任务实例、模板版本、状态、当前阶段和最后编辑时间。
- `task_points`：任务行数据及来源。
- `imported_templates`：安装后的 JSON 模板原文与版本。
- `devices`、`calibration_profiles`：设备和标定参数版本的扩展入口。
- `reports`、`settings`：报告索引与系统设置扩展入口。
- `audit_logs`：危险操作和参数变更审计的扩展入口。

正式标定阶段应通过数据库迁移新增或启用：设备、传感器、标定参数版本、标定点、检定结果、报告和用户权限表。参数版本只能新增，不能原地覆盖。

## 5. 安全联锁边界

当前 `DeviceSimulator` 实现 80% 提醒、90% 警告、2 秒趋势预测、98% 锁存预切断和 75% 以下人工复位。触发时它会停止记录、撤销 `controlOutputEnabled` 并发出 `emergencyTripRequested(pressure, reason)`。这只是上位软件向真实安全执行器提出请求的接口原型，Qt 页面本身不能承担最终保护。

正式系统必须至少分为三层：

1. 树莓派 UI/任务层：提示、记录、请求安全态和禁止后续操作。
2. 下位 MCU 安全层：独立看门狗、通信超时、ADC/传感器诊断和输出关断，不依赖 QML 是否运行。
3. 硬接线保护层：比较器、继电器、常闭阀/泄压阀或机械限压装置；断电、死机或线缆断开时进入定义的安全态。

软件不得绕过硬件锁存。复位应在压力降到公司确认的阈值以下、故障原因消失且由本机明确操作后执行，并将原因、峰值、时间、设备与参数版本写入审计记录。详细 I/O、状态机和公司确认清单见 `硬件安全联锁接口说明.md`。

## 6. 线程扩展

Demo 的模拟器与 SQLite 负载较低，可在同一事件循环验证产品流程。接入硬件后按以下方式拆分：

- UI线程：QML、输入和轻量 ViewModel。
- 串口线程：阻塞读取、帧拼接、CRC和重连。
- 数据线程：样本批量事务和历史查询。
- 计算线程池：拟合、不确定度、长时数据抽稀和报告准备。

跨线程只传不可变样本或值对象；QML 不持有串口对象和数据库查询对象。

## 7. 验收替换是否成功

- 拔插设备后 3 秒内给出明确连接状态，不丢失当前任务。
- 连续 30 分钟 50 Hz 采样无 UI 卡顿，序号丢失可统计。
- CRC 错误帧不进入正式样本表。
- 断开树莓派或杀死界面进程后，独立超压保护仍能切断压力源并进入安全态。
- 原始、滤波、温补值与公司上位机在同一测试点可对照。
- 停止记录后数据库样本数、首末时间和帧计数一致。
- 所有写参数命令包含读取回验、CRC验证、操作者与审计日志。
