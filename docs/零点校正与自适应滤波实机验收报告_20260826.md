# PressureOS 零点校正与自适应滤波实机验收报告

日期：2026-08-26  
软件版本：PressureOS 0.4.3（接口协议 V1.0）  
设备：Raspberry Pi + STM32F103RC + AD7124-8  
运行原则：温度只显示和记录，不参与压力补偿。

## 1. 本次改动

- 零点校正由单点读数改为 60 秒首次判定、最长 180 秒的多周期统计。
- 保留完整采样历史，使用中位数/MAD剔除偶发异常样本。
- 自动识别 4～90 秒规律振荡周期，至少取得两个完整周期后才允许写入偏移。
- 使用完整周期的时间加权中心、周期中心差、漂移斜率和均值标准误差共同判定。
- 校正失败时不改变原有零点偏移。
- 精密滤波由固定 20 秒平均升级为实际周期自适应滤波；真实压力阶跃仍走快速跟随路径，安全判断始终使用未延迟的标定原始值。
- 校正完成后用本次零点历史直接初始化滤波器，避免重新等待同一振荡周期。
- 零点向导和零漂任务页改为面向操作的简洁流程，移除密集算法说明。

## 3. 真实零点校正结果

零压环境下自动校正一次通过：

| 指标 | 结果 |
|---|---:|
| 有效样本 | 788 帧 |
| 完整周期 | 7 个 |
| 检测周期 | 7.536892 s |
| 写入零点偏移 | +0.241153754 kPa |
| 原始波形标准差 | 0.232254149 kPa |
| 原始波形峰峰值 | 0.692738673 kPa |
| 零点均值标准误差 | 0.008273711 kPa |
| 漂移斜率 | −0.000289554 kPa/s |
| 周期中心差 | 0.025990794 kPa |

该偏移来自完整周期统计，不是按钮按下时的一次瞬时读数。

## 4. 校正后独立复采

校正样本不参与复采验收。系统在校正结束后重新采集 30.070 秒、399 个样本：

| 验收项 | 门限 | 实测 | 结论 |
|---|---:|---:|---|
| 残余零点均值绝对值 | ≤ 0.020 kPa | 0.008559 kPa | 通过 |
| 滤波后截尾峰峰值 | ≤ 0.050 kPa | 0.049151 kPa | 通过 |
| 滤波后标准差 | 记录项 | 0.016520 kPa | — |
| 采样率 | ≥ 10 Hz | 13 Hz | 通过 |
| 复采期间协议错误 | 0 | 0 | 通过 |

结论：校正后不存在超过 0.02 kPa 的系统性零点偏差；自适应滤波对约 0.69 kPa 的规律原始振荡实现了明显抑制，同时没有使用温度补偿。

## 5. 使用要求

- 每次开机、重新安装测量头、改变软管连接或怀疑零点变化时，应在真实零压环境下重新运行零点漂移校正。
- 校正期间不得触碰传感器、接头或软管，不得施加压力。
- “周期抑制·精密”适合稳态示值和标定；测量真实动态压力波形时应切换到原始、中值或 IIR 模式，避免把真实周期变化当作干扰。
- 量程报警与变化率监测不使用长周期滤波结果，因此滤波不会延迟安全提示。
