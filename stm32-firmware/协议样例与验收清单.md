# PressureOS Serial Protocol V1 验收速查

## 通用格式

~~~text
@<payload>*<CRC16>\r\n
~~~

- CRC 范围：@ 之后、* 之前的全部 ASCII 字节。
- 算法：CRC-16/CCITT-FALSE。
- Poly=0x1021，Init=0xFFFF，RefIn/RefOut=false，XorOut=0x0000。

## 测量帧

~~~text
@PS1,M,<sequence>,<uptime_ms>,<pressure_raw>,<temperature_raw>,<status_flags>*<CRC>\r\n
~~~

固定 CRC 样例：

~~~text
@PS1,M,1523,483920,490980,9514440,00000000*3EC2\r\n
~~~

## 命令

~~~text
@PS1,C,42,PING*3527\r\n
@PS1,C,43,GET_INFO*4B8F\r\n
@PS1,C,44,ZERO*621A\r\n
~~~

- PING：返回 ACK。
- GET_INFO：返回 ACK 和 INFO。
- ZERO：本版返回 E_NOT_SAFE，不执行归零。

## 状态位

| 掩码 | 含义 |
|---:|---|
| 0x00000001 | ADC DRDY 超时 |
| 0x00000002 | ADC/SPI 通信错误 |
| 0x00000004 | 压力数据无效 |
| 0x00000008 | 温度数据无效 |
| 0x00000010 | 压力高于 600 kPa |
| 0x00000020 | 压力低于 -100 kPa |
| 0x00000040 | 温度陈旧或尚未更新 |
| 0x00000080 | ADC ERROR、POR 或传感器饱和故障 |
| 0x00000100 | 安全保护锁存（本版未接物理执行器） |
| 0x00000200 | 看门狗或异常复位 |
| 0x00000400 | ADC 配置或读回校验失败 |
