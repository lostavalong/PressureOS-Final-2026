PressureOS V1.0.10 使用说明
============================

一、启动方法
1. 安装版：双击 PressureOS_Setup_1.0.10_x64.exe，按安装向导操作。
2. 免安装版：先完整解压 ZIP，再双击 PressureOS.exe。
3. 不要只把 PressureOS.exe 单独复制出去；程序需要同目录中的 Qt 运行库和插件。

二、系统要求
- Windows 10/11 64 位。
- 建议屏幕分辨率不低于 1024×600。
- 无需预装 Qt、Visual Studio、数据库或其他开发环境。

三、数据与功能说明
- 测量任务、记录和模板数据保存在当前用户的本地应用数据目录中，升级或卸载程序不会主动删除这些数据。
- Windows 交付版默认使用内置模拟数据，适合页面、任务流程、滤波、拟合、导出和数据库功能的展示验收。
- STM32/CP2102N 真实串口采集、树莓派 Wi-Fi/蓝牙状态读取用于树莓派 Linux 实机版本；不能把 Windows 模拟数据作为正式计量结果。

四、常见问题
- Windows 若提示“已保护你的电脑”，是因为项目组没有商业代码签名证书。核对 SHA-256 后，可选择“更多信息”→“仍要运行”。
- 若程序无法启动，请确认 ZIP 已完整解压，不要直接在压缩软件预览窗口中运行。
- 数据库通常位于：%LOCALAPPDATA%\PressureOS Lab\PressureOS\pressureos_demo.sqlite
