# PressureOS 微信小程序交互 Demo

这是一个可以直接导入微信开发者工具的原生小程序工程。当前默认运行在 mock 模式，不依赖树莓派、PCB、云服务或网络，可以先验证页面、动线和交互；所有真实 REST/WSS 接口均集中封装，后续不会为了接硬件重写页面。

## 1. 当前已经实现

- 仪表首页：实时压力、趋势、温度、稳定性、量程使用率、设备状态与继续任务。
- 任务中心：按最后编辑时间排序、状态筛选、搜索、新建、删除和自动恢复。
- 由模板新建任务：选择模板、自定义任务名称、调整目标点数。
- 任务闭环：说明与安全确认 → 数据记录 → 自动分析 → 结果导出。
- 数据记录：手机输入外部变量、采用当前稳定压力、自动保存、逐点删除和重测。
- 数据分析：线性拟合方程、R、R²、RMSE、逐点残差、3σ嫌疑点、A/B类及合成/扩展不确定度。
- 模板库：分类、搜索、由模板创建任务、从微信文件选择JSON、安全校验和示例安装。
- 设备与配对：二维码解析、配对码/公钥指纹核对、能力授权和连接诊断。
- Mock数据持久化：任务和导入模板保存在小程序本地Storage，切换页面或退出后仍可恢复。
- 真实接口预留：REST请求、令牌、WSS实时流、断线指数重连和协议版本头。

## 2. 在微信开发者工具中运行

1. 安装微信开发者工具稳定版。
2. 选择“导入项目”。
3. 项目目录选择本文件所在的 PressureOS_WeChat_MiniProgram 文件夹。
4. 初次体验可使用测试号；工程里的 touristappid 只用于模拟器预览。
5. 点击“编译”，默认首页即会开始模拟实时压力。

工程无npm依赖，无需执行安装或构建命令。

推荐体验顺序：

1. “仪表”查看压力趋势、单位选择和进行中的任务。
2. 进入“任务”，打开“压力—质量关系实验 · 第二组”。
3. 在“记录”页依次使用快捷值 180 g、240 g、300 g 并采集。
4. 达到6点后进入“分析”，检查拟合、残差和不确定度。
5. 确认分析并体验结果导出。
6. 在“模板”中点击“导入JSON”，安装示例用户模板。
7. 在“设备”中查看权限边界，并体验模拟二维码配对。

如果要恢复初始体验数据，在开发者工具中清除本地缓存，或调用 mock/server.js 暴露的 reset()。

## 3. 切换真实树莓派接口

编辑 config/env.js：

    module.exports = {
      mode: "live",
      apiBaseUrl: "https://实际设备地址:8443/api/v1",
      websocketUrl: "wss://实际设备地址:8443/api/v1/stream",
      requestTimeoutMs: 8000,
      mobileStreamHz: 10,
      protocolVersion: "1.0"
    }

页面只能调用 services/api.js 和 services/realtime.js，不得直接写 wx.request、wx.connectSocket 或SQLite。真实接口字段和状态码见 docs/树莓派API对接表.md。

正式联调前还要完成：

- 使用真实小程序AppID。
- 配置微信公众平台的合法请求和WebSocket域名。
- 部署受信任的HTTPS证书；正式版不能依赖“关闭域名校验”或自签名证书。
- 树莓派实现短期令牌、权限、限流、审计和幂等处理。
- 明确局域网直连还是公司域名/云中继，真机验证微信平台限制。

## 5. 产品与安全边界

- 正式任务、原始数据、分析结果和报告的唯一权威端仍是树莓派。
- 手机掉线不能中断仪表采集，也不能导致任务丢失。
- 小程序只负责查看、任务辅助、人工变量、模板上传和分享。
- 归零、标定参数写入、量程修改、解除硬件联锁等操作必须在仪表本机确认。
- Mock中的统计计算只用于验证界面；Live模式必须显示树莓派返回的正式分析结果，页面不自行计算。
- 软件提示不能替代MCU和硬接线安全保护。
