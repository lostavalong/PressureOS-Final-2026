# PressureOS小程序交互验收清单

## 仪表

- [ ] 首页首屏能立即看懂当前压力、单位和连接状态。
- [ ] 压力变化时数字与趋势图流畅，不发生整页闪烁。
- [ ] 单位由下拉选取，不通过反复点击轮换。
- [ ] 量程、温度、稳定性和采样率文字清晰可读。
- [ ] 手机端明确标注只读，不出现危险控制入口。

## 任务

- [ ] 任务按最后编辑时间倒序排列。
- [ ] 同一模板可自定义名称并多次创建。
- [ ] 状态能区分待测数据、待分析、待导出和已完成。
- [ ] 退出任务后重新进入能恢复原阶段和数据。
- [ ] 左右轻扫与点击阶段导航均可切换已解锁阶段。
- [ ] 新用户在说明页能理解目的、流程、分析方法和安全事项。
- [ ] 数据点保存有明确反馈，重复点击不会重复写入。
- [ ] 错误点可以删除，删除后序号、进度和分析同步更新。
- [ ] 目标点不足时不能误进入正式分析。
- [ ] 拟合方程、R/R²、RMSE、残差和不确定度易于理解。
- [ ] 异常点只提示审核，不会被系统擅自删除。
- [ ] 返回记录页补测后，分析可以重新计算。
- [ ] 导出页能说明每种文件用途和版本可追溯性。

## 模板与配对

- [ ] 模板支持搜索、分类和由模板直接建任务。
- [ ] 超过1 MB、错误JSON或Schema不合格文件会被拒绝。
- [ ] 安装前展示校验结果和权限降级说明。
- [ ] 二维码配对需要核对设备ID、短期码和指纹。
- [ ] 仪表端未确认时不能获得写权限。
- [ ] 小程序清楚说明其没有归零、写参数和解除联锁权限。

## 异常

- [ ] Wi-Fi断开后显示重连状态，不把旧数据伪装为实时数据。
- [ ] 手机切后台再返回后实时流可恢复。
- [ ] 令牌失效会引导重新配对。
- [ ] 树莓派不可用时任务页面不丢失用户正在填写但尚未提交的内容。
- [ ] 手机掉线、退出或被杀进程不会中断树莓派采集和硬件保护。
